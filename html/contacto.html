El archivo de datos

Compruébelo usted mismo.

Este botón pide al servidor el archivo donde se guardan los mensajes y lo muestra tal cual, sin maquillar. Es la forma más directa de verificar que el formulario hace lo que dice. 

Pulse «Leer el archivo» para ver su contenido.

Tres rutas, un mismo archivo El sitio prueba primero api/guardar (la función de Node del hosting), luego guardar.php (el servidor con PHP de clase) y, si no hay ninguno —por ejemplo al abrir el proyecto directamente desde una carpeta—, guarda en el propio navegador y deja descargar el .txt.

Lo que no hace No hay base de datos todavía: en un hosting gratuito la función escribe en el almacenamiento temporal del servidor y el archivo se puede perder cuando la plataforma recicla la instancia. Con PHP en un servidor propio, datos/mensajes.txt es permanente. La base de datos llega en el Proyecto N.º 2.
